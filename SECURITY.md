# Security

To report a security problem, please use [private vulnerability reporting](https://github.com/orange9angel/dula-craft/security/advisories/new) instead of a public issue.

Include what you found, how to reproduce it and what it could affect. This project is maintained in spare time, so a reply may take a while.

## If your API key leaks

This project stores your voice key only on your own computer, and never receives it. If you've posted a key in public or shared it by mistake, revoke it in your provider's console and create a new one. Deleting the post isn't enough, because it may already have been copied.
