# 常见问题

没找到答案？到 [Discussions](https://github.com/orange9angel/dula-craft/discussions) 提问。

## 安装

**AI 说找不到这个 skill。**
请完全退出并重新打开 AI 工具。正在运行的会话不一定能看到新装的 skill。

**Qoder 里看不到这些 skill。**
在运行中的 Qoder CLI 里输入 `/skills reload`。Qoder CLI 通过 `~/.agents/skills` 找到它们。这一点在 Qoder CLI 上检查过，Qoder IDE 还没有验证。

**提示缺 git、Python 或 ffmpeg。**
安装命令见[配置说明](configuration.md#必需的软件)。装完要重新打开终端。

**Windows 提示“跳过……已有别的内容”。**
那个位置已经有同名的东西，安装程序不会覆盖。把它改名或移走，再安装一次。

**在 Git Bash 里运行 install.sh 报错。**
Windows 上请改用 PowerShell 命令。

**提示 “running scripts is disabled”。**
README 里的 `irm ... | iex` 写法通常不受影响，请确认复制了完整命令，并在 PowerShell 里运行。

## 出图

**没有 Codex CLI，能用吗？**
能。图片清单在 `build/images_todo.md`，用任何工具画好放到列出的路径，再运行一次同一条命令。

**Codex 报额度用完了。**
等额度恢复后重跑。已经画好的不会重画，也不会重复消耗。

**角色在不同的画里不像同一个人。**
确认设定图满意。不像的那张告诉 AI 删掉重画。被否决的画不要再当参考。

**抠图有残留背景、或者缺了一块。**
打开 `build/check_alpha.png`，在品红底上一眼就能看出来。告诉 AI 重画那一张。

## 嘴型和声音

**提示“嘴不会动”。**
这个角色在说话，但这张画没有嘴型变体。让 AI 补上。有意不动嘴（比如一声长叫），可以标记为例外。

**说话时嘴一直张着，或者动得太少。**
运行 `check_mouths.py` 看每句的换画次数；可能是音频太闷，也可能是嘴型变体只有一张。

**配音提示“密钥无效，或还没有开通”。**
确认开通了“音频生成 1.0”，并且 Key 是在语音控制台创建的，见[配置说明](configuration.md#配音)。

**全程有沙沙声。**
通常是环境音素材本身就是底噪，换一段。

## 效果和用途

**适合做什么？**
造型简单、以对话和表情为主的短片。复杂打斗、大幅连续动作和写实风格不适合这条流程。

**一支片子要多久？**
主要看出图速度。每张图大约 1–2 分钟，一支 30 秒的片子通常要几十张图。

**可以商用吗？**
本项目的 MIT 协议允许。第三方服务和素材要看各自的条款，见[版权和协议](licenses.md)。

**我的数据会上传吗？**
本项目不收集任何数据。见 [README 的隐私部分](../../README.zh-CN.md#隐私)。
